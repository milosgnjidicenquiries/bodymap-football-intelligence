# Criteria-to-evidence checklist

| Criterion (20% each) | Present proof | Work still required |
|---|---|---|
| Technological implementation | API, tests, seeded dataset, modular code | Microsoft SDK integration, cloud deployment, observability and perf profiling |
| Agentic design & innovation | Five traceable processing phases | Actual multi-agent model runtime, shared state, handoffs, recovery, evaluation |
| Real-world impact | Three audience selectors, tactical explainer | Real practitioner tests and usage measurements |
| UX & presentation | Responsive dashboard, animated replay, export | Full 3D engine, user tests, accessible polish, real video |
| Category adherence | Synthetic football use case | Official category eligibility, actual required AI/Microsoft integration, final project submission |

Scores are targets, not achieved grades. Consult the latest published official rules at https://github.com/microsoft/insidethegamehackathon/blob/main/OFFICIAL%20RULES.md.
